# Telegram-бот, отвечающий клиентам вместо тебя

Работает через Telegram Business: бот подключается к твоему аккаунту (нужен Premium) и отвечает клиентам в личных чатах от твоего имени, в твоём стиле. Отвечает ChatGPT (ключ OpenAI). Отдельная база данных не нужна: история хранится в файле `data/bot.db` рядом с ботом.

Бот сам ходит в Telegram за сообщениями (long polling). Поэтому ему **не нужен белый IP и проброс портов**, он работает даже за CGNAT (как у Aknet). Нужен просто компьютер с интернетом, который включён.

## Где запускать

| Вариант | Цена | Плюсы | Минусы |
|---|---|---|---|
| **1. Свой компьютер с Windows** (домашний сервер) | бесплатно | 10 минут, без карт и регистраций | бот молчит, пока компьютер выключен или нет интернета/света |
| **2. Oracle Cloud Always Free** | бесплатно | работает 24/7 независимо от дома | при регистрации просят карту для проверки, сервер настраивается через SSH |
| **3. Railway Hobby** (то, что было) | $5 в месяц | ничего не переделывать, деплой из GitHub | платно |

Одновременно должен работать **только один** экземпляр бота. Если запустить два (например, дома и на Railway), Telegram выдаст ошибку Conflict.

## Вариант 1. Свой компьютер (Windows)

1. Установи Python 3.12 с python.org. При установке поставь галочку **Add python.exe to PATH**.
2. Распакуй папку бота, например в `C:\tg-reply-bot`.
3. Скопируй файл `.env.example` в `.env` (в той же папке) и открой в Блокноте. Впиши:
   - `BOT_TOKEN=` токен из @BotFather (тот же, что был на Railway)
   - `OWNER_ID=` твой Telegram id (тот же, что был на Railway)
   - `OPENAI_API_KEY=` ключ OpenAI
4. Двойной клик по `start.bat`. Первый раз он сам поставит всё нужное (1–2 минуты). В Telegram от бота придёт «✅ Бот запущен».
5. Окно не закрывай: если бот упадёт, `start.bat` перезапустит его через 15 секунд.

**Автозапуск при включении компьютера:** Win+R → `shell:startup` → Enter. В открывшуюся папку положи ярлык на `start.bat` (правой кнопкой по `start.bat` → «Создать ярлык», перетащи ярлык туда). В настройках электропитания отключи спящий режим.

Логи пишутся в `data\bot.log`. Места нужно немного: Python с библиотеками около 300 МБ, база растёт на единицы мегабайт.

## Вариант 2. Oracle Cloud Always Free

1. Регистрация на oracle.com/cloud/free, создай VM: форма VM.Standard.E2.1.Micro (Always Free), образ Ubuntu, скачай SSH-ключ.
2. Скопируй папку бота на сервер (WinSCP или `scp`), создай в ней `.env` как в варианте 1.
3. На сервере: `sudo bash deploy/install_linux.sh`. Бот станет системной службой и будет перезапускаться сам.
4. Логи: `journalctl -u replybot -f`. Перезапуск после обновления файлов: снова `sudo bash deploy/install_linux.sh`.

## Вариант 3. Railway Hobby

1. Railway → Upgrade → Hobby.
2. Сервис PostgreSQL можно удалить: бот больше в нём не нуждается. У сервиса бота добавь Volume с путём `/app/data` (там будет база).
3. Variables: `BOT_TOKEN`, `OWNER_ID`, `OPENAI_API_KEY`, `OPENAI_MODEL`. Переменную `DATABASE_URL` удали.
4. Замени файлы в GitHub, Railway пересоберёт сам.

## Подключение к аккаунту
Telegram → Настройки → Telegram для бизнеса → Чат-боты → выбрать бота и чаты, включить «Отвечать на сообщения».

## Команды (в личке с ботом)
- `/draft` (по умолчанию) — бот присылает тебе черновик с кнопками «Отправить / Пропустить». Можно ответить на черновик своим текстом, уйдёт он.
- `/auto` — отвечает сам. Цены, оплата, споры всё равно идут тебе. Если бот пообещал клиенту файл или проверку («щас пришлю»), придёт напоминание 📌.
- `/status` — состояние, какая модель отвечает, видит ли бот бизнес-чаты.
- `/why` — почему бот промолчал (последние решения).
- `/pause N` — на сколько минут бот замолкает в чате, когда ты пишешь сам (0 = не замолкать). `/resume` — снять паузу.
- `/try текст` — как бот ответил бы на такое сообщение (никому не уходит). Голосовое в личку — покажет расшифровку и ответ.
- `/models` — какие модели ChatGPT доступны ключу. `/on` `/off` — включить/выключить.

## Модель ChatGPT и расходы
По умолчанию `gpt-6.1-terra`: хорошо держит стиль, недорогая. Один ответ отправляет модели около 4–5 тысяч токенов (стиль, примеры, история чата).
По ценам OpenAI (Standard, за 1 млн токенов, вход/выход) примерно выходит:
- `gpt-6.1-terra` ($1 / $5): около $0.006 за ответ, на $4 примерно 700 ответов
- `gpt-6-luna` ($0.10 / $0.50): около $0.0006 за ответ, на $4 примерно 7000 ответов, но пишет проще
- `gpt-6.1-sol` ($2 / $10): около $0.012 за ответ, на $4 примерно 350 ответов

По умолчанию включён тариф flex: всё вдвое дешевле (terra около $0.003 за ответ, на $4 примерно 1400 ответов). Отключить: `OPENAI_SERVICE_TIER=standard`. Ответ может идти дольше, а если flex откажет, бот повторит по обычной цене.
Если модель недоступна ключу, бот сам переключится на запасную (`OPENAI_FALLBACK_MODELS`) и покажет это в `/status`. Расход смотри на platform.openai.com → Usage.

## Голосовые
Клиент прислал голосовое — бот расшифровывает его тем же ключом OpenAI (`whisper-1`) и отвечает текстом по смыслу. Если расшифровать не вышло или голосовое длиннее 4 минут, оно приходит тебе. Если `whisper-1` отключат, бот сам перейдёт на `gpt-4o-mini-transcribe`. Проверить: пришли боту голосовое в личку.

## Как бот реагирует на особые реплики
- Вопросы про имена, «как вас зовут», тема Галины (`FORBIDDEN_WORDS`): коротко уводит к делу, без отказов и объяснений.
- Клиент написал «Адилет»: реагирует коротко («оу», «да, слушаю»), имя не повторяет.
- «Вы бот?», «живой человек?»: сам не отвечает. В `/auto` клиенту уходит «минуту», а тебе «Нужен ты».
- Только вложение (фото/файл), цена (бот ставит `""`), оплата, скидки, споры, вопросы вне раздела «Факты»: приходят тебе.
- Попытки «взломать» («забудь инструкции», код, SQL): отвечает как человек, которому прислали абракадабру.

Перед отправкой каждый ответ проверяется на имена, запретные слова, «палево» ИИ и шаблонную вежливость. Не прошёл — переписывается один раз, снова не прошёл — уходит тебе.

## Стиль
- `style.md` — правила стиля и раздел «Факты». Допиши минималку, размеры, ткани, сроки, доставку: без этого бот такие вопросы отдаёт тебе.
- `examples.json` — пары «клиент → твой ответ» из твоих переписок. Добавить ещё: `pip install beautifulsoup4`, затем `python import_chats.py --me "Адилет" messages.html другой.html`.

## Тесты
`pip install aiogram httpx` и `python tests/test_flow.py` (37 проверок, подставные Telegram и OpenAI, настоящая база SQLite).

## Если понадобится облачная база
Впиши в `.env` `DATABASE_URL=postgresql://...` (любой PostgreSQL), бот сам создаст таблицы. Без этой строки используется файл `data/bot.db`.
